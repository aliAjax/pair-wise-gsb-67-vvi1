# 光伏电站并网验收与缺陷闭环平台

基于Nuxt3、PrimeVue、Pinia、Nuxt Router、TanStack Query、ofetch、Vite和TypeScript的独立前端工程。Nuxt提供页面路由和服务端构建，业务数据在浏览器本地持久化。

## 功能

- 方阵、逆变器、汇流箱、变压器和并网点的设备树。
- 绝缘、接地、通信、保护、发电性能等验收项和证书附件。
- 建设单位、设备厂家、运维单位多方处理说明。
- 联合复验轮次、整改退回、带条件接受和关闭校验。
- 并网前完整性与证书有效期检查，签署锁定和交付包导出。
- 修订链：签署时冻结每个设备节点的依据版本并生成不可变快照；证书更新、验收项更正、缺陷重开只让源头节点及其上游（祖先）失效，其他节点继续有效；负责人对阻断节点逐项复核，全部恢复后从旧快照生成新修订版，旧快照保留可查。
- 现场离线同步包：回连后按字段对账，中心未改则快进现场版，同一字段两边都改则两版并存待裁定；同步中断按断点恢复，重复批次幂等、审计不重复追加。
- 设备与测试页、缺陷页、签署与审计页统一显示当前修订号、失效/阻断节点及历史快照只读视图。

端口为`18467`。

```bash
npm install
npm run build
npm run dev
```
